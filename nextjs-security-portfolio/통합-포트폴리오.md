# 2026 1·2학기 통합 포트폴리오

`nextjs-security-portfolio` 폴더에서 실행합니다.

```powershell
npm.cmd install
npm.cmd run dev
```

접속 주소: http://localhost:3000

`npm.cmd run dev`는 포트폴리오(3000)와 동아리 개인 프로젝트인 축구 웹(3001)을 함께 실행합니다. 축구 프로젝트 상세의 '축구 웹 열기'로 이동할 수 있습니다. 축구 웹 소스는 옆의 `football-analysis` 폴더에 있으며 최초 실행 전 해당 폴더에서도 `npm.cmd ci`를 실행합니다. 축구 데이터 조회에는 해당 앱의 `.env.local` 설정을 사용합니다.

- `/`: 두 학기의 성장 흐름, 프로필, 대표 프로젝트
- `/about`: 소개, 사용 기술, GitHub·블로그
- `/projects`: 전체·1학기·2학기 필터와 프로젝트 상세
- `/learning`: 1학기 과제 실습과 2학기 1~7주 학습 기록
- `/board`: 기존 2학기 데이터베이스·인증 실습 게시판

1학기 자료는 `public/semester-1`에서 제공합니다. HTML, CSS, JavaScript, 이미지와 미디어를 함께 보존했으며 각 HTML에는 통합 사이트로 돌아오는 링크가 있습니다. 작업 폴더의 `1학기 기말 포트폴리오/abc-main` 원본은 그대로 보존했습니다.

1학기 프로젝트·과제 목록: `lib/semesters.ts`
2학기 프로젝트·주차 목록: `lib/data.ts`
공통 디자인: `app/globals.css`

회원가입·로그인·게시글 저장은 기존 `.env.local`의 MongoDB와 인증 환경설정을 사용합니다.
