# 화면 정리 변경과 되돌리기

이번 변경은 홈 화면, 상단 메뉴, 프로젝트 목록, 공통 CSS 4개 파일에 적용했습니다.

- 소개·프로젝트·학습 기록을 홈에서 이어서 봅니다.
- 메뉴를 누르면 홈의 해당 위치로 이동합니다.
- 프로젝트는 목록에서 바로 실행하고, 구현 설명은 펼쳐서 읽습니다.
- 수업의 주차별 내용도 같은 화면에서 펼쳐봅니다.
- 기존 소개·프로젝트·학습 기록 상세 페이지는 그대로 열 수 있습니다.

기존 화면으로 되돌리려면 `nextjs-security-portfolio` 폴더에서 실행하세요.

```powershell
node .backups/before-navigation-simplify/restore.cjs
```

실행 후 브라우저를 새로고침하면 됩니다. 복원 직전 화면도 백업 폴더의 `replaced-숫자` 폴더에 저장됩니다. 이 명령은 위 4개 파일을 복원하며, 이후 해당 파일에 추가한 변경도 복원 직전 백업에 보관합니다. 동아리 설명, 축구 웹 연결, 1학기 자료에는 영향을 주지 않습니다.
