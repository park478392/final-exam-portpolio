# 페이지별 정리 변경 되돌리기

홈·소개·프로젝트·학습 기록을 별도 페이지로 유지하면서 제목, 여백, 메뉴와 링크를 정리했습니다. 현재 페이지는 상단 메뉴에 표시됩니다. 프로젝트에서는 상세 페이지와 실행 링크를 구분하고, 학습 기록은 주차별로 펼쳐볼 수 있습니다.

이번 변경 전 화면으로 복원하려면 프로젝트 폴더에서 실행합니다.

```powershell
node .backups/before-page-cleanup/restore.cjs
```

7개 기존 파일을 복원합니다. 복원 직전 파일도 `replaced-숫자` 폴더에 보관합니다. 추가된 `components/MainNav.tsx`는 복원 후 사용되지 않는 파일로 남으며 동작에 영향을 주지 않습니다. 기존 축구 웹과 원본 자료에는 영향을 주지 않습니다.
